### O QUE É O SCRATCH?


📖 **APRENDA**

O Scratch é um programa onde você cria jogos, histórias e animações — **sem precisar escrever código de texto**.

Em vez de digitar comandos complicados, você usa **blocos coloridos** que se encaixam como peças de quebra-cabeça. Cada bloco faz uma coisa: mover, falar, tocar um som, mudar de cor.

Você decide quais blocos usar e em que ordem. Isso é programar.

**Para que serve o Scratch?**
- Criar jogos
- Fazer animações
- Contar histórias interativas
- Aprender lógica de programação de forma visual

> 💡 **DICA:** O Scratch foi criado pelo MIT — um dos institutos de tecnologia mais famosos do mundo — justamente para quem está aprendendo a programar pela primeira vez.

## MÓDULO 2 — PRIMEIROS BLOCOS

---

### EVENTOS — O PONTO DE PARTIDA

📖 **APRENDA**

Um **evento** é o que dá início a uma ação no projeto. É como um gatilho.

Sem um evento, os blocos que você programou **nunca vão rodar**.

Os eventos mais usados:

- 🟨 **"quando a bandeira verde for clicada"** → Inicia quando você clica na bandeira verde
- 🟨 **"quando este ator for clicado"** → Inicia quando você clica no personagem

> 💡 **DICA:** Todo projeto começa com um bloco de evento. Sem ele, é como ligar um motor sem combustível.

🛠️ **PRATIQUE**

Crie uma pequena apresentação onde o personagem diz:
> "Olá! Meu nome é \_\_\_\_\_\_. Seja bem-vindo!"

---

### MOVIMENTO

📖 **APRENDA**

Para mover um personagem no Scratch, use os blocos da categoria **Movimento** (em azul).

| Bloco | O que faz |
|---|---|
| **mova 10 passos** | Move o personagem para a frente |
| **gire 15 graus** | Gira o personagem |
| **aponte para a direção 90** | Define a direção do movimento |
| **vá para x: 0 y: 0** | Leva o personagem para uma posição específica |
| **deslize em 1 segundo até x: 0 y: 0** | Move suavemente até um ponto |

> 💡 **DICA:** O palco usa coordenadas X e Y. X é horizontal (esquerda-direita). Y é vertical (cima-baixo). O centro é X=0, Y=0.

🚀 **DESAFIO**

Faça o personagem **atravessar o palco da esquerda para a direita** e depois **voltar para o centro**.

---

### APARÊNCIA

📖 **APRENDA**

Os blocos de **Aparência** (em roxo) controlam como o personagem aparece na tela.

| Bloco | O que faz |
|---|---|
| **diga Olá! por 2 segundos** | Exibe um balão de fala |
| **pense Hmm... por 2 segundos** | Exibe um balão de pensamento |
| **mude para a fantasia costume1** | Troca a aparência do personagem |
| **mostre** | Torna o personagem visível |
| **esconda** | Torna o personagem invisível |
| **mude o tamanho para 100%** | Define o tamanho do personagem |

🛠️ **MINIATIVIDADE**

Crie uma animação onde o personagem:

☐ Aparece (use o bloco "mostre")
☐ Fala alguma coisa
☐ Muda de aparência
☐ Se movimenta

### SOM

📖 **APRENDA**

Som é parte da experiência do jogador. Um jogo sem som parece incompleto.

No Scratch você pode:
- Usar sons da biblioteca
- Gravar sua própria voz
- Adicionar efeitos sonoros

| Bloco | O que faz |
|---|---|
| **toque o som Meow** | Reproduz o som escolhido |
| **toque o som Meow até terminar** | Espera o som acabar antes de continuar |
| **pare todos os sons** | Para todos os sons em execução |

> 💡 **DICA:** Adicione um efeito sonoro quando o personagem coletar um ponto ou perder uma vida. O jogador entende melhor o que está acontecendo.

## MÓDULO 3 — LÓGICA DE PROGRAMAÇÃO

---

### SEQUÊNCIA — A ORDEM IMPORTA

📖 **APRENDA**

O computador executa os blocos **de cima para baixo**, um de cada vez. Isso chama de **sequência**.

Se você trocar a ordem dos blocos, o resultado muda.

**Exemplo:**
```
INICIAR
↓ falar "Olá!"
↓ andar para a direita
↓ tocar som
↓ mudar de cenário
```

> ⚠️ **ATENÇÃO:** Se você colocar "mudar de cenário" antes de "falar", o personagem vai mudar de cenário sem ter falado nada primeiro.

🛠️ **ATIVIDADE**

Crie uma sequência com pelo menos **5 ações** que contem uma história curta.

---

### REPETIÇÃO — FAZENDO AS COISAS MAIS DE UMA VEZ

📖 **APRENDA**

Imagina que você quer que o personagem ande 10 passos 100 vezes. Você não vai colocar 100 blocos iguais, certo?

Para isso existe o **loop** (repetição).

| Bloco | O que faz |
|---|---|
| **repita 10** | Repete os blocos dentro dele 10 vezes |
| **sempre** | Repete infinitamente (até o projeto parar) |
| **repita até \<condição\>** | Repete até uma condição ser verdadeira |

**Exemplo — personagem andando continuamente:**
```
quando a bandeira verde for clicada
  sempre
    mova 10 passos
    se tocar na borda, volte
```

🚀 **DESAFIO**

Crie uma animação que **não precise repetir manualmente os mesmos blocos**. Use o bloco de repetição.

---

### CONDIÇÕES — SE ISSO, ENTÃO AQUILO

📖 **APRENDA**

Uma condição é uma pergunta que o programa faz. A resposta é sempre **SIM ou NÃO**.

Dependendo da resposta, o programa faz coisas diferentes.

**Formato:**
```
SE [algo é verdade]
  ENTÃO [faça isso]
```

**Exemplos:**
- SE o personagem tocar na borda → ENTÃO ele volta
- SE o jogador coletar uma moeda → ENTÃO some 1 ponto
- SE os pontos chegarem a 10 → ENTÃO o jogador vence

> 💡 **DICA:** Condições são a base de qualquer jogo. Sem elas, nada reage ao que o jogador faz.

---

### SENSORES — O PROJETO QUE REAGE

📖 **APRENDA**

Sensores detectam o que está acontecendo no jogo:

| Bloco | O que detecta |
|---|---|
| **tocando em [cor]?** | Se o personagem tocou em uma cor específica |
| **tocando em [ator]?** | Se tocou em outro personagem |
| **posição x do mouse** | Onde o mouse está na horizontal |
| **tecla [espaço] pressionada?** | Se o jogador pressionou uma tecla |
| **distância até [ator]** | A distância entre dois personagens |

🛠️ **ATIVIDADE**

Faça um personagem **reagir quando o jogador clicar nele**. Pode ser uma fala, um som ou uma animação.

### CRIANDO O PERSONAGEM

📖 **APRENDA**

No Scratch, personagens se chamam **Atores** (ou Sprites). Cada ator pode ter:

- **Fantasias** — diferentes aparências (para animações)
- **Sons** — sons próprios
- **Código** — blocos de programação só para ele

**Para escolher ou criar um personagem:**
1. Clique no ícone de personagem no canto inferior direito
2. Escolha entre:
   - **Biblioteca** — personagens prontos
   - **Pintar** — crie do zero
   - **Câmera** — use sua câmera
   - **Upload** — suba uma imagem

🚀 **DESAFIO**

Crie um **personagem próprio** usando o editor do Scratch.

---

### CRIANDO O CENÁRIO

📖 **APRENDA**

O cenário é o fundo do seu jogo. Ele também pode mudar durante o projeto.

**Para adicionar um cenário:**
1. Clique no ícone de cenário no canto inferior direito
2. Escolha entre biblioteca, pintar ou upload

> 💡 **DICA:** O cenário não é só decoração. Ele conta parte da história. Um cenário de floresta diz muita coisa antes de o personagem falar qualquer palavra.

---

### PONTUAÇÃO — VARIÁVEIS

📖 **APRENDA**

Uma **variável** é como uma caixinha que guarda uma informação. Essa informação pode mudar ao longo do jogo.

**Exemplos de variáveis em um jogo:**
- `PONTOS` — vai aumentando conforme o jogador joga
- `VIDAS` — vai diminuindo quando o jogador erra
- `TEMPO` — uma contagem regressiva
- `NÍVEL` — indica o nível atual

**Para criar uma variável:**
1. Clique em **"Variáveis"** no menu de categorias
2. Clique em **"Criar uma Variável"**
3. Dê um nome a ela (ex: PONTOS)

🛠️ **ATIVIDADE**

1. Crie uma variável chamada **PONTOS**
2. Faça ela começar com o valor **0** quando o projeto iniciar
3. Faça ela aumentar **1 ponto** cada vez que o personagem tocar em um objeto

---

### VIDAS E DERROTA

📖 **APRENDA**

Quase todo jogo tem vidas. Veja como criar:

**Configuração inicial:**
```
quando a bandeira verde for clicada
  mude VIDAS para 3
```

**Quando sofrer dano:**
```
quando tocar em [inimigo]
  mude VIDAS por -1
  se VIDAS = 0
    diga "Game Over!" por 2 segundos
    pare o projeto
```

> ⚠️ **ATENÇÃO:** Não esqueça de definir o valor inicial das variáveis quando o projeto começar. Senão, o jogo vai continuar de onde parou na última vez.

---

### VITÓRIA

📖 **APRENDA**

Assim como existe derrota, deve existir vitória. O jogador precisa saber quando ganhou.

**Exemplo de condição de vitória:**
```
se PONTOS = 10
  diga "Você venceu!" por 3 segundos
  pare o projeto
```

🛠️ **ATIVIDADE**

Adicione uma condição de vitória ao seu jogo. O jogador deve ver uma mensagem clara quando ganhar.

---

### TESTANDO E CORRIGINDO (DEBUGGING)

📖 **APRENDA**

**Debugging** é o processo de encontrar e corrigir erros no código. É uma habilidade essencial de qualquer programador.

Quando algo não funciona, não entre em pânico. Use o checklist:

**☐ O bloco está conectado?**
Verifique se os blocos estão encaixados corretamente.

**☐ O evento foi iniciado?**
Tem um bloco de evento no topo (bandeira verde, clique...)?

**☐ A variável está com o valor certo?**
Use o monitor de variáveis para verificar o valor atual.

**☐ O personagem está no lugar certo?**
Talvez ele esteja fora da tela.

**☐ Existe alguma condição impossível?**
Exemplo: "se PONTOS = 10.5" quando os pontos só são números inteiros.

**☐ O código está sendo executado?**
Clique no bloco diretamente para ver se ele roda.

> 💡 **DICA:** Erros no código se chamam **bugs**. Corrigir bugs se chama **debugging**. Todo programador do mundo faz debugging — isso é normal.

### O QUE É UM SITE?

📖 **APRENDA**

Antes de falar sobre WordPress, vamos entender o que é um site.

Quando você digita um endereço no navegador (como `google.com`), o que você vê é um **site**. Um site é um conjunto de páginas publicadas na internet.

**Analogia:**

| Conceito | No mundo real | Na internet |
|---|---|---|
| **Domínio** | Endereço da rua | `www.meusite.com.br` |
| **Hospedagem** | O terreno onde a casa fica | Servidor que guarda o site |
| **Site** | A construção | As páginas que o visitante vê |

Um site pode ter uma página só, ou pode ter muitas. Pode ser de uma escola, de um negócio, de uma pessoa, de um evento.

---

### O QUE É O WORDPRESS?


📖 **APRENDA**

O **WordPress** é um sistema para criar e gerenciar sites. Você não precisa saber programar para usá-lo.

Ele é chamado de **CMS** (Sistema de Gerenciamento de Conteúdo). Isso significa que ele organiza todo o conteúdo do seu site: textos, imagens, páginas, menus.

**O que você pode fazer com WordPress:**
- Criar páginas (Sobre, Contato, Serviços...)
- Publicar posts (como notícias ou artigos de blog)
- Adicionar imagens e vídeos
- Escolher a aparência do site (usando temas)
- Adicionar funcionalidades (usando plugins)

**WordPress.com × WordPress.org**

| | WordPress.com | WordPress.org |
|---|---|---|
| O que é | Serviço pronto, hospedagem incluída | Software que você instala |
| Para quem | Iniciantes | Quem tem mais controle técnico |
| Nesta oficina | ✅ Vamos usar este | |

> 💡 **DICA:** O WordPress.com é mais fácil para começar. Você cria uma conta e já começa a construir seu site — sem precisar contratar hospedagem.

---

### ESTRUTURA DE UM SITE

📖 **APRENDA**

Um site bem organizado tem uma estrutura clara. O visitante precisa saber onde está e para onde ir.

**Estrutura típica:**
```
INÍCIO
  ├── SOBRE
  ├── CONTEÚDO / SERVIÇOS
  └── CONTATO
```

**O que cada página costuma ter:**

| Página | Conteúdo |
|---|---|
| **Início** | Apresentação principal, imagem de destaque, chamada para ação |
| **Sobre** | Quem você é, qual a história, qual o propósito |
| **Conteúdo** | O assunto principal do site |
| **Contato** | Formulário ou informações de contato |

### TRABALHANDO COM TEXTO

📖 **APRENDA**

No editor do WordPress, você pode formatar o texto de várias formas:

| Elemento | Quando usar |
|---|---|
| **Título (H1)** | O título principal da página. Use apenas um por página. |
| **Subtítulo (H2)** | Divisões principais do conteúdo. |
| **Subtítulo (H3)** | Subdivisões dentro de uma seção. |
| **Parágrafo** | Texto normal. |
| **Lista** | Itens em sequência ou tópicos. |
| **Negrito** | Para destacar algo importante. |

> ⚠️ **ATENÇÃO:** Não transforme seu site em um "paredão de texto". Use títulos, listas e imagens para quebrar o conteúdo.

---

### IMAGENS

📖 **APRENDA**

Imagens tornam o site mais atraente e comunicam mais rápido que texto.

**Para adicionar uma imagem:**
1. Clique em **"+"** no editor para adicionar um bloco
2. Escolha **"Imagem"**
3. Clique em **"Upload"** para enviar uma imagem do seu computador
4. Ou clique em **"Biblioteca de mídia"** para usar uma imagem já enviada

**Texto alternativo (Alt Text)**

Sempre adicione uma descrição à imagem no campo **"Texto alternativo"**.

Exemplo: *"Foto do grupo de estudantes do projeto Programando o Futuro"*

> 💡 **DICA:** O texto alternativo é lido por leitores de tela para pessoas com deficiência visual. Isso chama **acessibilidade**.

---

### CORES E IDENTIDADE VISUAL

📖 **APRENDA**

A identidade visual é o conjunto de cores, fontes e estilos que fazem o site ter uma aparência consistente.

**Regras básicas:**
- Use no máximo **2 ou 3 cores principais**
- Use no máximo **2 fontes** (uma para títulos, outra para texto)
- Mantenha o mesmo estilo em todas as páginas

**Contraste:** O texto deve ser fácil de ler. Texto claro em fundo claro é difícil de ler.

✅ Bom: texto preto em fundo branco
❌ Ruim: texto amarelo em fundo branco

---

### MENUS E NAVEGAÇÃO

📖 **APRENDA**

O menu é o que o visitante usa para navegar pelo site. Ele costuma aparecer no topo da página.

**Para criar um menu:**
1. Vá em **Aparência → Menus**
2. Dê um nome ao menu
3. Adicione as páginas que você quer no menu
4. Defina onde o menu aparece (cabeçalho, rodapé...)
5. Salve

🛠️ **TESTE:**

*"Consigo chegar a qualquer página do site em, no máximo, 2 cliques?"*

Se a resposta for não, seu menu precisa ser reorganizado.

---

### TEMAS

📖 **APRENDA**

Um **tema** define a aparência geral do site: cores, fontes, layout, posição dos elementos.

Trocar o tema não apaga o seu conteúdo — só muda como ele é exibido.

**Para escolher um tema:**
1. Vá em **Aparência → Temas**
2. Explore as opções disponíveis
3. Clique em **"Ativar"** para aplicar

> 💡 **DICA:** Escolha um tema simples para começar. Temas muito complexos têm mais opções e podem confundir no início.

### PLUGINS

📖 **APRENDA**

**Plugin** é um recurso adicional que você instala para adicionar funções ao site.

É como instalar um aplicativo no celular: o celular já funciona, mas o aplicativo adiciona uma função nova.

**Exemplos:**
- Plugin de formulário de contato
- Plugin de galeria de imagens
- Plugin de backup
- Plugin de SEO (para aparecer no Google)

> ⚠️ **ATENÇÃO:** Não instale plugins aleatoriamente. Instale apenas o que você precisa e que seja de fontes confiáveis. Plugins desatualizados podem deixar o site vulnerável.

---

### RESPONSIVIDADE

📖 **APRENDA**

Responsividade significa que o site **se adapta automaticamente** ao tamanho da tela.

Um site responsivo funciona bem no:
- Computador
- Tablet
- Celular

Hoje em dia, a maioria das pessoas acessa sites pelo celular. Se o site não funcionar bem no celular, você perde visitantes.


🛠️ **ATIVIDADE**

Reduza a janela do navegador até ficar estreita. O site continua legível?

### ACESSIBILIDADE

📖 **APRENDA**

Acessibilidade significa que o site pode ser usado por qualquer pessoa, incluindo pessoas com deficiências.

**Checklist de acessibilidade básica:**

☐ O contraste entre texto e fundo é suficiente?
☐ O tamanho da fonte é legível (mínimo 16px)?
☐ As imagens têm texto alternativo?
☐ Os links descrevem para onde vão (não use "clique aqui")?
☐ Os títulos estão em ordem (H1, depois H2, depois H3)?
☐ O site não depende apenas de cores para passar informação?

## MÓDULO 7 — GOOGLE SITES

---

### O QUE É O GOOGLE SITES?


📖 **APRENDA**

O **Google Sites** é uma ferramenta do Google para criar sites de forma simples e rápida.

A diferença principal em relação ao WordPress:
- É mais simples de usar
- Se integra com Google Drive, Google Docs, Google Forms
- Não precisa de hospedagem separada
- O site fica na conta Google

**Para acessar:**
Acesse [sites.google.com](https://sites.google.com) e faça login com uma conta Google.

---

### CONHECENDO A INTERFACE

📖 **APRENDA**

A tela do Google Sites é dividida assim:

| Área | Função |
|---|---|
| **Painel de páginas (esquerda)** | Mostra todas as páginas do site |
| **Área de edição (centro)** | Onde você edita o conteúdo |
| **Painel de inserção (direita)** | Elementos que você pode adicionar |
| **Botão "Visualizar"** | Ver como o site ficará para o visitante |
| **Botão "Publicar"** | Publicar o site na internet |

---

### CRIANDO A PRIMEIRA PÁGINA

🛠️ **PRATIQUE — Passo a passo**

1. Acesse [sites.google.com](https://sites.google.com)
2. Clique em **"+"** para criar um novo site
3. Clique no título e **dê um nome ao seu site**
4. Clique no cabeçalho e **adicione um título principal**
5. Clique em **"Inserir"** e adicione um bloco de texto
6. Escreva um texto de apresentação
7. Adicione uma imagem
8. Clique em **"Visualizar"** para ver como ficou
9. Clique em **"Publicar"**

---

### TRABALHANDO COM LAYOUTS

📖 **APRENDA**

O Google Sites organiza o conteúdo em **seções**. Cada seção pode ter layouts diferentes:

- Texto simples
- Imagem + texto lado a lado
- Grade de imagens
- Cabeçalho com imagem de fundo

> 💡 **DICA:** Varie os layouts para deixar o site mais interessante. Uma página com tudo em coluna única fica monótona.

---

### CRIANDO NOVAS PÁGINAS

📖 **APRENDA**

Para adicionar uma nova página:
1. No painel da esquerda, clique em **"+"**
2. Dê um nome à página
3. A página aparece automaticamente no menu de navegação

**Estrutura sugerida:**
```
INÍCIO
  ├── SOBRE
  ├── PROJETO
  └── CONTATO
```

---

### INSERINDO CONTEÚDO

📖 **APRENDA**

No Google Sites, você pode inserir vários tipos de conteúdo pelo painel "Inserir":

| Conteúdo | Como inserir |
|---|---|
| **Texto** | Clique em "Caixa de texto" |
| **Imagens** | Clique em "Imagem" e faça upload |
| **Vídeos do YouTube** | Cole o link do vídeo |
| **Google Forms** | Conecte um formulário criado no Forms |
| **Google Maps** | Cole o link de um local |
| **Arquivos do Drive** | Conecte documentos, planilhas ou apresentações |

---

### PERSONALIZAÇÃO

📖 **APRENDA**

Para personalizar a aparência do Google Sites:

1. Clique em **"Temas"** no painel da direita
2. Escolha um tema base
3. Você pode ajustar:
   - Cor principal
   - Fonte dos títulos
   - Imagem do cabeçalho

> ⚠️ **ATENÇÃO:** O Google Sites tem menos opções de personalização que o WordPress. Isso é proposital — ele é mais simples.

---

### ORGANIZAÇÃO E DESIGN

📖 **APRENDA**

**Menos é mais.**

Um site com muito conteúdo, muitas cores e muitas fontes é mais difícil de ler do que um site simples.

**Evite:**
- Mais de 3 cores diferentes
- Mais de 2 fontes diferentes
- Imagens sem relação com o conteúdo
- Parágrafos muito longos
- Informações repetidas

---

### PUBLICAÇÃO E COMPARTILHAMENTO

📖 **APRENDA**

1. Clique em **"Publicar"** no canto superior direito
2. Defina o endereço do site (ex: `sites.google.com/view/meu-projeto`)
3. Escolha quem pode ver:
   - Qualquer pessoa na internet
   - Apenas pessoas com o link
   - Apenas pessoas da sua organização
4. Clique em **"Publicar"**
